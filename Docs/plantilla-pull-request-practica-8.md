## Limitaciones conocidas

Los servicios de Open Library pueden fallar o proporcionar datos incompletos; algunas sinopsis y etiquetas están en inglés. Los favoritos son locales; no hay sincronización entre dispositivos. La accesibilidad completa requiere comprobación manual. La inicialización de SwiftData no tiene recuperación alternativa si falla el contenedor.
